# Plan d'action · Objectif Ingénieur

Une page HTML autonome pour piloter tes projets d'alternance (NaTran) et d'école (ISTP) : projets, actions, Gantt, planning, jalons et journal de bord.

**Aucune installation, aucun code.** Double-clique sur `index.html` et la page s'ouvre dans ton navigateur (Chrome ou Edge recommandés).

## Ce que tu y trouves

| Fenêtre | À quoi elle sert |
|---|---|
| **Tableau de bord** | Compte à rebours jusqu'au diplôme, parcours avec les jalons clés, priorités de la semaine, actions en retard, avancement de chaque projet |
| **Projets** | Une carte par projet (NaTran / ISTP / Perso) : avancement, santé (*dans les temps*, *à surveiller*, *en retard*), prochain jalon |
| **Page projet** | Vue d'ensemble (objectifs, courbe d'avancement réel/prévu, charge), actions, Gantt, planning, jalons et journal propres au projet |
| **Actions** | Liste filtrable ou tableau Kanban (glisser-déposer), ajout rapide, checklist, dépendances, charge estimée |
| **Gantt** | Zoom jours / semaines / mois, glisser une barre pour la déplacer, tirer ses bords pour changer ses dates, flèches de dépendances |
| **Planning** | Calendrier mois / semaine : glisse une échéance ou un jalon vers un autre jour |
| **Jalons** | Frise chronologique des étapes clés et de leurs actions liées |
| **Journal de bord** | Notes datées et **revue hebdomadaire** guidée (ce qui a avancé, blocages, priorités) |
| **Paramètres** | Profil, logos, sauvegardes, thème clair/sombre |

## Sauvegarde

- **Automatique et permanente** : chaque modification est enregistrée instantanément dans le navigateur (l'indicateur « Enregistré · hh:mm » en haut le confirme).
- **Copie dans un fichier** (Chrome / Edge) : *Paramètres → Sauvegarde → Choisir un fichier*. Le fichier `.json` est réécrit à chaque modification. Mets-le dans OneDrive ou un dossier synchronisé pour le retrouver partout.
- **Points de restauration** : une copie par jour est conservée (14 jours).
- **Export / import** : pour changer d'ordinateur ou archiver (`.json`), et export des actions en `.csv` pour Excel.
- **Ctrl + Z** annule la dernière modification.

> Les données restent dans le navigateur utilisé. Si tu vides les données de navigation ou changes de navigateur, utilise ton fichier de sauvegarde ou un export pour les retrouver.

## Logos

La page affiche des logos provisoires tant que les logos officiels ne sont pas fournis. Deux façons de les ajouter :

1. **Dans la page** : *Paramètres → Logos → Importer une image* (PNG, SVG ou JPG).
2. **Par fichier** : dépose `logo-natran.png` (ou `.svg`) et `logo-istp.png` dans le dossier `assets/` à côté de `index.html`.

## Raccourcis

`/` rechercher · `N` nouvelle action · `Ctrl + Z` annuler · `Ctrl + S` forcer la sauvegarde · `Échap` fermer une fenêtre.

# Plan d'action · NaTran — Objectif Ingénieur

Une page HTML autonome pour piloter tes projets d'alternance (NaTran) et d'école (ISTP) : projets, plan d'action, Gantt, planning, jalons et journal de bord.

**Aucune installation, aucun code.** Double-clique sur `index.html` : la page s'ouvre dans ton navigateur (Chrome ou Edge recommandés). Les logos NaTran et ISTP sont intégrés au fichier.

Au premier lancement, la page contient ton plan Excel *Plan_action_NaTran_v7_avec_Gantt* : le projet **PRJ-001 — Harmonisation du suivi maintenance multi-sites**, ses **40 actions** réparties en 10 phases et ses **10 jalons (J1 → J10)**.

## Les fenêtres

| Fenêtre | À quoi elle sert |
|---|---|
| **Tableau de bord** | Compte à rebours jusqu'au diplôme, boutons rapides, indicateurs (actions ouvertes, avancement, en retard, échéance ≤ 7 j, bloquées), *À traiter en priorité*, prochains jalons, vue synthétique des projets, répartition des actions |
| **Projets** | Une carte par projet : ID, chef de projet, avancement, risque, santé (*dans les temps*, *à surveiller*, *en retard*) |
| **Page projet** | Objectif, livrables, commentaire/arbitrage, avancement par phase, risques & décisions, courbe réel/prévu, plan d'action, Gantt, planning, jalons, journal. Bouton imprimante = **fiche projet PDF** |
| **Plan d'action** | Actions groupées par phase, filtres (statut, responsable, priorité), statut et avancement modifiables d'un clic, ajout rapide, vue Kanban |
| **Gantt** | Projets → phases → actions, jalons J1…J10, zoom jours/semaines/mois, glisser-déposer pour replanifier |
| **Planning** | Calendrier des dates cibles, des *prochains points* et des jalons |
| **Jalons** | Frise chronologique (jalon, livrable, décision, réunion, Go/No Go) |
| **Journal de bord** | Notes et **revue hebdomadaire** guidée |

Les champs reprennent ceux de ton classeur : ID projet / ID action, axe/lot, résultat attendu, responsable, priorité, statut (À lancer, En cours, En attente, Bloqué, Terminé, Annulé), avancement, date début, date cible, alerte délai, prochaine étape, date prochain point, risque/blocage, décision/arbitrage, commentaires.

## Excel

*Paramètres → Excel* :
- **Exporter en Excel** : un classeur avec les onglets Projets, Plan d'action, Jalons et Journal, avec les mêmes colonnes que ton modèle.
- **Importer un Excel** : relit les onglets *Projets*, *Plan d'action* et *Planning Gantt* de ton modèle. Ce qui existe déjà (même ID) est mis à jour, le reste est ajouté.

L'import/export Excel télécharge un module à la demande : il faut une connexion Internet. Hors ligne, l'export CSV fonctionne toujours.

## Sauvegarde

- **Automatique** : chaque modification est enregistrée tout de suite dans le navigateur (indicateur « Enregistré · hh:mm »).
- **Copie dans un fichier** (Chrome / Edge) : *Paramètres → Sauvegarde → Choisir un fichier*, par exemple dans OneDrive.
- **Points de restauration** : une copie par jour, 14 jours.
- **Ctrl + Z** annule la dernière modification.

> Les données restent dans le navigateur utilisé. Si tu vides les données de navigation ou changes de navigateur, utilise ton fichier de sauvegarde ou un export pour les retrouver.

## Raccourcis

`/` rechercher · `N` nouvelle action · `Ctrl + Z` annuler · `Ctrl + S` forcer la sauvegarde · `Échap` fermer
